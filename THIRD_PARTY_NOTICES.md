# Sources, attribution and licensing

Every study identifies the paper being reproduced and records the source locations and hashes used. The programme-authored runners and auditors analyse or reconstruct that work; paper authors are not presented as authors or endorsers of this reproduction programme.

Third-party papers, author code, raw participant/model-response datasets, model weights, package binaries and large arrays are generally not redistributed. INPUTS.json supplies source/acquisition records. Obtain those materials from their owners under their own terms. Public availability does not establish a license, and an unknown license remains unknown. Where upstream license text is present in a source inventory, it is evidence about that material only and does not license the whole release.

No blanket software/content license has been assigned. Publishing this repository does not add a permissive license to the original reproduction code or reports. The repository owner may select a license separately; that choice must not relicense third-party data or software. Dependency names in requirements.txt are installation references; their libraries are not vendored here.

PROVENANCE.json records the origin and original/publication hashes of included files. Most code is programme-authored; upstream data/code is represented by acquisition metadata. Scientific quotations, paper titles and published numerical reference values remain attributed to the cited work. This notice is an attribution and packaging description, not a legal determination about every upstream asset.
