## Source-method conflicts affect interpretation

The original released code and displayed Figure 2 use a **classical normal confidence interval for composite scores (panel B)**, although the Methods and figure caption claim that every random-effects interval uses HKSJ. Following the actual original code gives MD 4.88447 [0.65352, 9.11542]. Applying the prose's HKSJ method instead gives **[-22.54430, 32.31324]**, which crosses zero. The published significance claim therefore depends materially on this inconsistency. Both computations are retained; the original figure was the prospectively chosen target, with the conflict recorded before any outcomes.

Panel A's code and figure use **inverse-variance common-effect pooling**, yielding RR 1.44250, whereas Methods prose specifies Mantel-Haenszel. The independently computed MH point is 1.48485. The supplement's GRADE table gives a different accuracy RR (1.63) from the central figure (1.59), and rounds one composite-study CI differently from the original R input SE. These conflicts were documented in the original preregistration; no central panel or failed criterion was removed.

## Preserved failure and method correction

P066-central-001 used an effectively exact PM root (tolerance 1e-13), passing 68/69 checks. Its panel A prediction upper endpoint was 163.689428 versus the printed 163.67 and failed the fixed 0.01 tolerance. This failed run remains immutable.

Reviewing declared **meta 8.2-1** source established that its estimator calls metafor's PM solver. Contemporary **metafor 4.8-0** uses R uniroot with tolerance double.eps to the one-quarter power (0.0001220703125), maxiter 100 and source-defined adaptive bounds. The declared **R 4.5.2** root-solver source was archived and independently translated. SOLVER_CORRECTION.json disclosed this method correction before P066-central-002, retaining exactly the original 69 gates and tolerances. The same original solver was applied to **all three panels**, without selecting a fitted endpoint or parameter.

The corrected panel A tau-squared is 0.0762919687, producing prediction upper 163.673305, which passes the original tolerance. Original inputs, target values and target hashes are unchanged. The author did not identify their installed metafor version; 4.8-0 is the contemporary primary dependency release, while the exact original meta and R versions are explicitly stated. This dependency-version uncertainty remains a limitation.
