The runner uses unclustered HC2 robust standard errors and n-rank Student-t inference, as in the source lm_robust calls. The authors' exact installed estimatr/metafor package versions are not released. Historical estimatr 1.0.4 source and current official documentation establish the same HC2 default; this version uncertainty remains disclosed. Original metafor method="FE" is reconstructed with inverse-variance precision weights and normal Wald inference.

P072-audit-001 separately rereads all original RDS files, reinterprets each source-defined selection and feature specification, verifies participant-selection hashes including duplicate rows, and recomputes every treatment fit with pivoted QR rank and triangular-QR HC2 covariance. It uses separate Counter aggregation for sample counts and QR ANOVA for attrition; it does not import the runner. It independently recomputes all original target decisions and checks frozen source/run hashes, timing, formulas' row identities and the retained correction. All **14,552/14,552 audit checks pass**.

## Original source choices and retained failures

The reproduction preserves the original analysis rather than silently repairing its choices:

- Tables S22/S23 say "collapsed across all study 3 conditions" in their caption, while the original estimator filters treatment-1 only. The code-defined estimator is reproduced.
- Durability uses participants complete at immediate and follow-up phases. The stacked study-1 dialogue/static phase estimator is unclustered, as in the original source.
- The original non-information subgroup already contains control participants and then appends controls again. This duplication is preserved; the information subgroup appends controls once.
- The scaling-input S6/S7 study-2 model uses the released models_vs_control labels, pooling its deceptive-info participants with the corresponding Llama-405b label. Separate post-training estimates use their own source filters excluding treatment-3. Both original estimators are retained.
- Original RDS date columns produce a reader warning because of missing dates. These columns are not used in the selected models. The original source files and warning are retained.

Every failed attempt remains:

1. P072-central-001 completed calculation but failed saving a NumPy integer to JSON. Its source, design file and failure record are retained. Only scalar serialization was corrected before the next run.
2. P072-central-002 saved every computed table and decision: **2,449/2,470** passed, with 21 failed S6/S7 study-2 gates. It also failed in the final console-only JSON printing after the saved outputs. The failed statistical result is retained.
3. The mismatch was traced to a reconstruction error: S6/S7 were mapped to the separate additional-analysis script's deceptive-arm recoding. Original 4_results_tables.R lines 184-198 instead uses ols_dialogue from function_scaling_curve.R, whose original unweighted model uses unchanged models_vs_control. The exact source evidence and correction were recorded at environment/source_mapping_correction_before_run003.json before P072-central-003. Only that mapping and console scalar serialization changed. The independent audit verifies that the only altered model definitions are these two study-2 S6/S7 designs; all recipes, syntheses, data, targets, tolerances and scope remain unchanged.
4. The earlier missing-reader-dependency import and a source-schema file-location mistake were retained. The reader dependency was installed in an isolated paper-local vendor folder from archived free wheels.

The failed run-002 manifest names the then-current global runner. Its exact source survives at runs/P072-central-002/runner_before_source_mapping_correction.py with the manifest's original runner hash. The successful run and audit additionally archive immutable copies of their exact source.

## Explicit omissions

This contribution does not reproduce fresh model training/generation or recruit new participants. It omits the paper's separate Bayesian Student-t model-scale meta-regressions, GAM/LOO/census-weighted scaling-curve syntheses (S8-S21), model-derived claim extraction/factual accuracy and main Figure 4, Bayesian latent claim-count/perceived-informativeness correlations/slopes (S62-S69), random-forest analysis, secondary human informativeness/demographic/conversation-length statistics, and derived prose percentages/curve digitization. The original private dialogue text is not publicly released. These omissions were fixed before outcomes; full-paper success is not claimed.
